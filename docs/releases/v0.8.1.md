# GoCode v0.8.1 — New Providers & Current Model Catalog

**Released:** 2026-11-27

v0.8.1 adds three provider gateways and refreshes the default models across the
existing providers to their current catalogs, so a fresh install talks to models
that still exist.

## New providers

- **Command Code** (`commandcode`) — the Command Code Provider API
  (`https://api.commandcode.ai/provider/v1`, OpenAI Chat Completions and
  `/models`, `CMD_API_KEY`). API access is included on every plan except the $1
  Go plan: **GOAT**, Pro, Max, Team and Provider all work, and one key serves
  both the CLI and the API.
- **OpenCode Go** (`opencode-go`) — the subscription tier of OpenCode's gateway
  (`https://opencode.ai/zen/go/v1`, `OPENCODE_API_KEY`), a curated coding subset
  on the same OpenAI-compatible surface as the pay-as-you-go Zen tier.
- **Mistral Vibe** (`mistral-vibe`) — Mistral's Vibe coding model on la
  Plateforme (`MISTRAL_API_KEY`, default `mistral-large-4-0`); switch to
  `devstral-medium-latest` or `mistral-medium-latest` for the coding-tuned
  variants.

All three are built-in presets, overridable like any gateway via
`[provider.<name>]` or a `custom` entry.

## Provider catalog refresh

Several default models had been retired or superseded; the defaults now point at
current models:

| Provider | Was | Now |
|---|---|---|
| OpenAI | `gpt-4o` | `gpt-6.2-sol` |
| Anthropic | `claude-sonnet-4-20250514` | `claude-sonnet-5-5` |
| Gemini | `gemini-2.5-flash` | `gemini-3.5-flash` |
| Groq | `llama-3.3-70b-versatile` | `openai/gpt-oss-120b` |
| Qwen | `qwen-max` | `qwen3.8-max` |
| Kimi | `api.moonshot.cn` + `moonshot-v1-8k` | `api.moonshot.ai` + `kimi-k3.1-pro` |
| xAI | `grok-code-fast-1` | `grok-4.7` |
| MiniMax | `MiniMax-M2.5` | `MiniMax-M3.1-Flash` |
| DeepSeek | `deepseek-chat` | `deepseek-flash` |
| Cerebras | `qwen-3-coder-480b` | `qwen-3.8-27b` |
| Zhipu | `glm-4.6` | `glm-5.2` |
| NVIDIA | `qwen/qwen3-coder-480b-a35b-instruct` | `qwen/qwen3-next-80b-a3b-instruct` |

Groq's Llama 3.3, Kimi's moonshot-v1 series, MiniMax M2.5 and DeepSeek's
`deepseek-chat` were all retired upstream, so those defaults would have failed
on a fresh install. Aggregator defaults (OpenRouter, Together, Fireworks) stay
delegated to each provider's `/models` list because their catalogs rotate per
account. The docs note the regional endpoints (Kimi `.ai`/`.cn`, Zhipu
`z.ai`/`bigmodel.cn`, Qwen international `dashscope-intl`).

## Verification

- `gofmt`, `go build`, `go vet` clean; the full test suite passes; `-race` clean;
  `staticcheck` clean; streaming benchmark unchanged at 0.165 block-renders/chunk.
- `gocode provider list` resolves every gateway to a current model.
