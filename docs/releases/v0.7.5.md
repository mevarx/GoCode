# GoCode v0.7.5 — Harness & TUI Upgrade

**Released:** 2026-11-19

This release ports the best mechanisms from a source-level study of the oh-my-pi coding agent into GoCode's existing seams: structured turn lifecycle with provider-reported usage, automatic pair-safe compaction with overflow recovery, streamed tool arguments and mid-turn steering on the harness side; a render cache, shared-clock animation system, command registry, palette, and live pickers on the TUI side. No security boundary moved: approval still precedes every mutation, redaction stays unconditional, and tool-call/result pairing survives every abort path.

## Harness

- **Structured turn lifecycle** — every turn emits turn-start and exactly one turn-end event carrying metrics (tokens, tool calls, elapsed, retries) on all exit paths, including abort and loop-guard stops. The TUI status line shows context-%, last-turn tokens and elapsed time; headless `turn_done` carries a metrics object; the plain REPL prints a turn summary.
- **Provider-reported usage** — token counts are parsed from OpenAI-compatible, Anthropic and Ollama streams when present; opt-in `[provider] stream_usage` asks gateways for `stream_options.include_usage`. Context accounting takes the larger of the local estimate and the provider report, so provider-side compression cannot hide growth.
- **Automatic compaction** — history is pruned and summarized before it hits the limit: cuts land only at whole-turn user boundaries (a tool result never separates from its call), reserve-based threshold math stays sane on small windows, and maintenance runs pre-round and post-turn. A provider context-overflow error now triggers compaction and one bounded retry instead of silently dropping turns; last-resort truncation announces what it dropped. Old tool output is elided to token-count placeholders with the newest ~40k tokens protected. Manual `/compact` is unchanged.
- **Stable prompt prefix** — environment, plan and scratchpad moved into one trailing dynamic block, so the static prompt prefix stays byte-identical across turns for provider prompt caches. Untrusted-context delimiters and marker neutralization are unchanged.
- **Tool-argument streaming** — arguments stream to the UI as the model writes them on all three dialect paths; pending cards fill in live. Deltas are display-only: approval and execution still wait for complete arguments. Headless gains an additive `tool_delta` frame.
- **Mid-turn steering** — `Enter` while streaming queues guidance instead of being ignored; it is applied at the next provider-round boundary with a notice and a queued chip. Headless accepts `{"type":"steer"}` mid-turn (turns run asynchronously; piped user input stays ordered).

## Terminal UI

- **Render cache** — settled messages render once (message value equality is the change signal, width the invalidation epoch); only the live tail and mutating cards re-render. Streamed updates coalesce to ≤30 redraws/s with discrete events immediate. Measured: block-renders per chunk stay constant at 0.165 for 200 vs 2000 settled messages — roughly 25–55× faster than the old per-token full re-render. Autoscroll now correctly follows long sessions; the perpetual idle tick is gone.
- **Animation system** — one shared wall-clock spinner clock (80ms braille frames, boundary-aligned ticks) frame-locks the status bar and every pending tool card; streamed text and tool-arg previews reveal at max(3, ceil(backlog/8)) clusters per 30fps tick without splitting combining marks; a classic shimmer band sweeps the working state word; cards show elapsed badges.
- **Motion gate** — `[tui] motion = "auto" | "reduced" | "off"` and `smooth_streaming`, honoring terminal reduced-motion. Functional indicators degrade to static glyphs and 1s data refreshes — they never disappear. Mouse wheel scrolls the transcript.
- **Live cards & pickers** — tool cards show pending/running/✓ done/✗ error states; `/sessions` opens a fuzzy session picker (Enter resumes through the engine's validated path); the model picker refreshes on open with bounded concurrent collection and snapshot fallback.
- **Overlay stack** — approval always wins focus: a tool request can never hide behind the palette or picker.

## Commands & documentation

- **Command registry** — dispatch, generated `/help`, Tab completion and the Ctrl+K fuzzy palette read one table; help can no longer drift. All 13 commands behave identically, including `/commit` approval and `/model` fail-closed validation. Arg-taking palette selections stage at the prompt instead of running with defaults.
- **Keymap as data, completion, history** — every legacy binding preserved; Tab completes commands and `/model`/`/provider` arguments; Alt+P/Alt+N (and Up on an empty prompt) recall prompt history.
- **New references** — `docs/architecture.md`, `docs/configuration.md` (full strict TOML surface), `docs/providers.md` (20 built-ins, custom endpoints, auth flows, Copilot/Hermes/llama.cpp/OpenCode Zen guides) fix the three broken README links; README/CONTRIBUTING refreshed. The design study lives in `docs/omp-reverse-engineering.md` with cited evidence under `docs/research/`, and the phase record in `PLAN.md`.

## Upgrade notes

- New config keys (all defaulted, strict decode): `[provider] stream_usage` (false), `[context] auto_compact` (true) and `keep_recent_tokens` (20000), `[tui] motion` ("auto") and `smooth_streaming` (true).
- Automatic compaction is **on by default**; set `[context] auto_compact = false` for the old manual-only behavior.
- `Enter` while streaming now queues steering instead of being ignored; `Esc`/`Ctrl+C` cancel semantics are unchanged.
- Headless: `turn_done` gains an additive `metrics` object; new `tool_delta` frames and `steer` input records. Existing drivers keep working.
- In the TUI, bare `/sessions` opens the picker; the plain terminal and headless keep the text list.
- Ctrl+K opens the command palette; Ctrl+L still opens the model picker (now refreshing).

## Security

No boundary changed: approval-before-mutation, the single redaction transcript boundary, synthetic tool results on abort, untrusted-context delimiters, and path confinement are intact and test-defended. `govulncheck ./...` reports 0 affecting vulnerabilities; `staticcheck ./...` is clean. A reachability dead-code sweep found nine helpers unreachable from `main` — all are exercised by active tests (including `WrapExecution` security contracts) and were kept.

## Known limitations

- Steering queued after the final round boundary is dropped at turn end (no synthetic continuation round).
- A card under the approval modal reads "running": the engine announces tool start before approval and has no separate "approved" event.
- Each coalesced flush still pays bubbles' viewport line scan (bounded at 30/s); block renders are O(1).
- The session picker is briefly empty until the SQLite listing lands.
- 23 tests skip on Windows for environmental reasons (file modes, symlinks, cmd.exe timeout semantics); CI covers them on Linux/macOS.
