# GoCode v0.8.0 — Themed Terminal UI & Upgraded Agent Harness

**Released:** 2026-11-21

v0.8.0 is a major upgrade to both the terminal UI and the agent harness. The
TUI gains a full semantic colour-theme system, a sidebar layout, rich markdown
rendering, polished dialogs, a complete chat keymap and a shared-clock
animation system. The harness gains structured turn metrics, automatic
context compaction with summary-anchored replay, a permission service, a
13-event hook engine, a generic event bus and queued-turn dispatch with
cancel-on-entry.

No security boundary moved: approval still precedes every mutation, redaction
and the deny-list stay unconditional, and tool-call/result pairing survives
every abort path.

## Terminal UI

- **Theme system** — the TUI is painted entirely from semantic colour tokens.
  Six built-in themes ship (`gocode-dark` default, `gruvbox-dark`, `keanu`,
  `rose-pine`, `rose-pine-moon`, `rose-pine-dawn`), each a fully resolved
  palette with CIELAB-derived diff tints and a contrast-checked badge ink.
  User themes are JSON files with base inheritance in the config `themes/`
  directory. Switching themes repaints every style and invalidates the render
  caches without dropping cached heights. Light mode is a theme
  (`rose-pine-dawn`), not an adaptive-color guess. New `[tui] active_theme`
  and `transparent` settings, a `Ctrl+T` theme picker with live preview and a
  `Ctrl+E` palette editor.
- **Layout** — a one-cell outer frame; a 32-column right sidebar with a
  gradient wordmark, model/provider, workspace and live turn metrics; a
  universal 2-cell chat gutter with a 120-column content cap; a borderless
  editor with a fixed 4-cell prompt column; a merged status/help row; and a
  compact mode below 120×30 that collapses the sidebar into a one-row header.
- **Markdown, tool cards & diffs** — assistant messages render as full
  markdown through glamour with a per-theme chroma configuration shared by
  code blocks, file views and diffs. Tool cards use a plain head (spinner,
  state word, elapsed) over an indented, tinted body with faint params.
  Unified diffs render as two-band tinted rows in both the transcript and
  approval previews.
- **Dialogs & badges** — rounded primary frames with a gradient title rule
  over an undimmed backdrop, borderless mnemonic buttons, WCAG-contrast
  badges, and destructive/warning variants. The permission dialog gains input
  grace (it only delays keys, never approves), danger-flagged requests that
  default to Deny, and split/fullscreen diff toggles. Idle `Ctrl+C` opens a
  quit confirmation. The session switcher gains deleting and renaming.
- **Keymap, focus & completions** — a focus enum (editor/main/sidebar) with a
  clear dispatch contract; a full chat keyset (line scroll, item selection
  with scroll-into-view, half-page and full paging, top/bottom, follow);
  central OSC 52 copy with a toast; an `@file` completion popup with
  gitignore-aware bounded async walk and four-tier ranking; and per-workspace
  prompt history with draft save/restore. Status toasts replace the status
  row briefly with sequence-stamped expiry.
- **Shared clock & scramble spinner** — one generation-guarded 50ms clock
  drives everything animated: flush coalescing, spinner scramble, elapsed
  badges, the opt-in reveal pacer and the mascot springs. Exactly one
  outstanding tick; stale generations are dropped; an idle session arms
  nothing. Streamed text renders on arrival by default; the motion gate still
  degrades decoration to static while data keeps refreshing.

## Agent harness

- **Event bus** — a generic in-process pubsub broker with three delivery
  classes (lossy, bounded must-deliver, and coalescing by entity key), counted
  drops and an overflow resync signal. The loop publishes every event; the
  TUI and headless front-ends consume one fan-in pump each, with a turn-end
  gate that keeps done messages from overtaking bus events. The headless
  JSONL schema is unchanged.
- **Permission service** — the approval gate becomes a request/grant service
  with `normal`/`yolo` modes (`[permissions] mode` and `--yolo`). YOLO
  auto-grants safe calls but refuses dangerous ones; the deny-list and
  redaction stay unconditional in every mode. A conservative danger
  classifier feeds the modal's Deny-default. Session grants are keyed by
  session/tool/action/path; resolution is atomic first-answer-wins on
  server-stored parameters, prompts serialize per scope, and cancellation
  denies without hanging.
- **Hook engine** — shell hooks on 13 lifecycle events with Claude
  Code-compatible stdin/stdout JSON payloads, exit-code semantics
  (0/2/49/other), parallel execution with per-hook timeouts and config-order
  aggregation. Hooks can block a call, rewrite its input or output, add
  context, or halt a turn. A hook allow can never bypass the permission
  deny-list or transcript redaction. Configured via the strict `[hooks]` TOML
  section.
- **Context management** — transcript repair guarantees a valid provider
  wire shape (orphan results dropped, real results preferred over interrupted
  placeholders, results re-emitted beside their calls). Compaction persists a
  flagged summary row and anchors replay at it, so a resumed transcript reads
  from the summary onward with the plan/todo list restated. Stop conditions
  add a remaining-context backstop and a signature-window guard that catches
  interleaved repeat loops. Session persistence is debounced and coalesced,
  with synchronous flush on terminal transitions so a cut-short turn loses
  nothing.
- **Queued-turn dispatch** — a per-session state machine with a monotonic
  accept-sequence and cancel high-water mark decides atomically whether a
  prompt runs, queues, or is cancelled on entry. Cancellation is cooperative
  (partial assistant output is kept) and settles every dropped prompt with a
  terminal event so no caller hangs. The TUI shows pending turns; headless
  accepts an additive `cancel` input.

## Security

Unchanged and unconditional: approval-before-mutation, secret redaction at
every transcript boundary, the permission deny-list outranking every mode,
grant and hook, tool-call/result pairing on every abort path, and
untrusted-context delimiter neutralization. The read-only-grant reset now
fires only for executing turns, so a queued or cancelled call can never clear
a running turn's grants.
